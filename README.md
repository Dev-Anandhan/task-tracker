# Placement Survival Tracker ⚡

A mobile-friendly, ADHD-optimized daily routine and task tracker designed for high-intensity placement sprint preparation.

## Features

- **Sprint Schedules**: Structured plans including 3-Day Sprint Focus & Master Routines.
- **Micro-Task Checklists**: Time-blocked task breakdowns with instant progress tracking and completion percentages.
- **ADHD Distraction Anchor**: "Parked Thoughts / Distractions" scratchpad to offload random thoughts without derailing focus.
- **Local Persistence**: Automatically saves check states, active tabs, and notes in browser `localStorage`.
- **Fast & Responsive**: Built with Tailwind CSS and vanilla JavaScript; zero heavy runtime dependencies.

## Getting Started

Simply open `tasktracker.html` in any modern web browser or host it via GitHub Pages.
